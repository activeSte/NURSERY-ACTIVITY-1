Lesson 1 — Installing Anaconda

Anaconda is a free package that brings Python + 250 scientific libraries (NumPy, pandas, scikit-learn, TensorFlow) + the Jupyter Notebook editor in a single installer.

Steps

  1. Go to anaconda.com/download and pick your OS.
  2. Install with default options (≈ 3 GB).
  3. Open Anaconda Navigator → launch Jupyter Notebook.
  4. Create a new notebook → kernel Python 3.
  5. Type and run print("Hello, NN!").

Useful conda commands (terminal)

conda create -n nncourse python=3.11
conda activate nncourse
conda install numpy pandas matplotlib scikit-learn
pip install tensorflow
jupyter notebook
Why Anaconda instead of plain Python? Anaconda solves dependency hell: scientific libraries (BLAS, MKL, CUDA) are pre-compiled and isolated in environments, so a project for class never breaks a project for work.

Indentation = grammar

Unlike Java or C++, Python uses spaces (4 by convention) instead of { } to mark blocks. Wrong indentation = syntax error.

# sum the first 10 squares
total = 0
for i in range(1, 11):
    total += i**2          # 4-space indent
print("Sum =", total)      # → Sum = 385

Lists, dictionaries, functions

prices = [12.5, 9.0, 4.75]          # list
stock  = {"bread":40, "milk":12}    # dictionary

def total(values, vat=0.22):
    return sum(values) * (1 + vat)

print(total(prices))                # → 31.99

Lesson 3 — Python vs Java, C++/C#, Turbo Pascal, Fortran

Same task: read 10 numbers, print their average. Look at how much each language asks you to write.

🐍 Python (8 lines) 
nums = []
for _ in range(10):
    nums.append(float(input()))
print(sum(nums)/len(nums))
☕ Java (≈ 18 lines) 
import java.util.Scanner;
public class Avg {
  public static void main(String[] a){
    Scanner s = new Scanner(System.in);
    double t = 0;
    for (int i=0;i<10;i++) t += s.nextDouble();
    System.out.println(t/10);
  }
}
💠 C# (Visual C#) 
using System;
class Avg{
  static void Main(){
    double t=0;
    for(int i=0;i<10;i++) t += double.Parse(Console.ReadLine());
    Console.WriteLine(t/10);
  }
}
⚙️ Visual C++ 
#include <iostream>
int main(){

  for(int i=0;i<10;i++){ std::cin>>x; t+=x; }

When to pick what

  • Python → prototypes, AI, data analysis, school projects.
  • Java / C# → robust desktop / web / mobile applications.
  • C++ → real-time control of a CNC mill, embedded firmware.
  • Pascal → historical, still didactic for structured programming.
  • Fortran → heavy numerical simulations (CFD, FEM) where every microsecond counts.

Lesson 4 — Neural-network algorithms in 6 steps

  1. Neuron: output = activation(Σ wᵢ·xᵢ + b)
  2. Layer: many neurons working in parallel.
  3. Network: layers stacked (input → hidden → output).
  4. Loss: a number that says "how wrong are we?" — e.g. MSE = mean((y−ŷ)²).
  5. Backpropagation: gradient of loss w.r.t. each weight.
  6. Gradient descent: w ← w − η · ∂L/∂w.

Minimal NN in Python (Keras)

from tensorflow import keras
import numpy as np

X = np.array([[0,0],[0,1],[1,0],[1,1]])
y = np.array([0,1,1,0])     # XOR

model = keras.Sequential([
    keras.layers.Dense(4, activation='relu', input_shape=(2,)),
    keras.layers.Dense(1, activation='sigmoid')
])
model.compile(optimizer='adam', loss='mse')
model.fit(X, y, epochs=500, verbose=0)
print(model.predict(X).round())

Lesson 5 — Metalmechanical applications Metal

5.1 — Predict tool wear on a lathe

Inputs: cutting speed v (m/min), feed f (mm/rev), depth d (mm). Output: expected tool life T (min). Train a small NN on workshop data.

import numpy as np
from sklearn.neural_network import MLPRegressor

# columns: v, f, d   →   T
data = np.array([[120,0.2,1.0, 45],
                 [150,0.3,1.5, 28],
                 [100,0.1,0.8, 70],
                 [180,0.4,2.0, 15]])
X, y = data[:, :3], data[:, 3]
nn = MLPRegressor(hidden_layer_sizes=(8,), max_iter=5000).fit(X, y)
print("Predicted T for v=130,f=0.25,d=1.2 →", nn.predict([[130,0.25,1.2]]))

6.3 — Ohm's law data fit with a NN

Even if V = R·I is linear, training a 1-neuron network on (I, V) pairs learns R as the weight. Great visual demo of how a network discovers a physical constant.

import numpy as np
from sklearn.linear_model import LinearRegression
I = np.array([[0.1],[0.2],[0.3],[0.4]])
V = np.array([0.47, 0.95, 1.42, 1.90])
m = LinearRegression().fit(I, V)
print("Estimated R =", round(m.coef_[0], 2), "Ω")

7.3 — Predict next-month sales with a NN

Inputs: month number, marketing spend, average temperature. Output: forecasted sales in €. A regression NN (1 hidden layer, 16 neurons) is plenty for small shop data and lets students see training loss dropping during model.fit.

from sklearn.neural_network import MLPRegressor
import numpy as np
X = np.array([[1, 200, 8],[2, 250, 10],[3, 300, 14],
              [4, 280, 18],[5, 320, 22],[6, 400, 27]])
y = np.array([3200, 3500, 4100, 4600, 5200, 6100])
nn = MLPRegressor(hidden_layer_sizes=(16,), max_iter=8000).fit(X, y)
print("July forecast →", round(nn.predict([[7, 420, 30]])[0]), "€")
